## 验证与验收

- 工作台主要空间用于转录，移动/窄屏仍可完成核心操作；
- 回看期间不强制跳到底部，返回最新后恢复跟随；
- 重连/replay 不重复 final；
- ASR/AI 失败不停止原始录音；
- unit、typecheck、build 和真实 Chromium 合成数据场景通过；
- 完成后提交 GitHub，由项目负责人审查。
