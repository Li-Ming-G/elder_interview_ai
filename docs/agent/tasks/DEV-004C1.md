## 交付与验收

- 新 provider/runtime namespace 即新 `speaker_stream_id`；同名短 label 不继承；event stream 不参与 mapping；
- begin/resolve 与当前 PCM 串行泵有序，冻结不可变 sequence/session-timeline 半开区间；begin 前和 resolve 后 delayed final 分类正确；
- provider 自动角色始终 unconfirmed，用户确认后才产生 trusted role；
- 校准控制片段由服务端 attempt 标记并从下游消费排除；
- GET、begin、resolve、session.ready 与 WS 1.1 updated 使用同一 `SpeakerCalibrationSnapshot` mapper；
- fail/skip/retry 不停止录音，unknown 门禁可验证；
- 新流重新确认，旧证据不改写；
- Android 小屏明确正在录音、确认/待确认/重试，触控 ≥44×44px；
