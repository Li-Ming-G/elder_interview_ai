## Goal

Freeze one formal provider-neutral Runtime Orchestration V1 contract for T18–T24 before changing the existing question-generation runtime.

The contract must define how finalized transcript events, P1/P2 work, automatic generation, manual-next, generation fencing, publication, deadline/error and Decision Trace interact.

## Scope

Freeze exact rules for:

- finalized-ASR driven buffering/debounce;
- automatic generation gate;
- manual-next priority/bypass semantics;
- generation identity and stale/late result fencing;
- presentation revision / snapshot publication authority;
- deadline and timeout behavior;
- `SYSTEM_ERROR` versus `CONTINUE_LISTENING`;
- P1/P2 background isolation;
- replay/idempotency/restart semantics;
- Decision Trace references and terminal outcomes.

Existing runtime constants such as the current automatic minimum interval and generation deadline are compatibility baselines. This task freezes ownership/semantics; it does not product-tune new numeric values.

## Required Behavior

1. Interim ASR never directly triggers Director generation.
2. Finalized transcript may feed a bounded buffer/debounce path.
3. Automatic generation must not call Director for every finalized segment.
4. Existing automatic minimum interval remains the compatibility gate unless a later owner-approved contract changes its numeric value.
5. Manual-next may bypass automatic debounce/minimum-interval waiting, but never bypass authorization, idempotency, current presentation/snapshot authority, deletion/retention or publication fencing.
6. Every generation has one stable generation/request/attempt identity.
7. Only a result still authoritative for the current presentation basis may publish. A stale/late generation cannot replace a newer result.
8. Manual-next starting from a newer accepted basis makes an older automatic result unable to publish.
9. Timeout, provider/tool/context/P3/P4/evidence/runtime failure is represented as `SYSTEM_ERROR`/unavailable according to existing public compatibility surfaces; it must never silently become `CONTINUE_LISTENING`.
10. Genuine Director `CONTINUE_LISTENING` remains a successful semantic decision, distinct from failure.
11. P2 background work must not block recording, finalized ASR or Director.
12. Memory/P1 failure follows already accepted lane semantics and must not corrupt question publication authority.
13. Replay/restart uses existing durable AiJob/attempt/trace authority rather than a new orchestration truth store.
14. Decision Trace remains append-only/reference-oriented and records trigger, generation, fence, deadline, stage, error and publication outcome.
15. No new agent framework, second Director, second presentation authority or second semantic memory authority.
