## Goal

Integrate exactly one optional read-only evidence drill-down round into the existing Director generation boundary, with deterministic no-loop behavior and `SYSTEM_ERROR` on tool failure, while keeping the production provider/model/prompt choice deferred.

## Scope

Wire the accepted P5E-01 contract and P5E-02 read-only tools into the existing question-generation orchestration seam using provider-neutral/synthetic-capable interfaces. A generation may:

1. use the frozen P4 context;
2. request zero or one accepted evidence tool invocation;
3. receive the bounded evidence result;
4. produce one final QUESTION or CONTINUE_LISTENING result.

No second evidence request is permitted.

## Required Behavior

1. Each generation gets `evidence_round_count = 0` initially and can invoke at most one accepted P5 evidence tool. A second request, recursive request or parallel multi-tool fanout fails closed.
2. Evidence requests are validated against the exact frozen P4/generation scope before tool execution. No ad-hoc ID/query widening.
3. Tool success returns only the accepted bounded result into the internal Director evidence round. It does not mutate the frozen P4 membership/digest or business truth.
4. Tool failure, malformed result, authorization/retention/deletion failure, stale source or one-round violation yields `SYSTEM_ERROR`. It must not become `CONTINUE_LISTENING`, a fallback question, or a V1 context fallback.
5. Zero tool calls remains a valid path and must preserve existing QUESTION/CONTINUE_LISTENING behavior.
6. Decision Trace records safe evidence metadata/references: invoked yes/no, tool identity, count, stage, error code/result reference/count, and duration. It must not copy raw transcript/evidence bodies.
7. Stale generation/head/fence semantics already present in runtime remain authoritative; late evidence result cannot write a newer presentation/attempt state.
8. Production provider/model/function-calling SDK and T25 prompt remain deferred. Tests may use deterministic synthetic/test doubles to exercise the evidence-request branch.
9. No hidden tool loop or agent framework is introduced.
