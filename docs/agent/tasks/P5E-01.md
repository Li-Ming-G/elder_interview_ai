## Required Behavior

1. `get_memory_evidence` is read-only and accepts only a memory identity already present and readable in the current generation's frozen P4 membership. It cannot be used as arbitrary project-wide memory lookup.
2. `search_transcript` is read-only and limited to the current frozen job/P4-authorized project/session scope. It cannot search another project, untrusted/interim/deleted/retention-ineligible transcript, or bypass existing policy gates.
3. Evidence results return source transcript segment references plus bounded neighboring context needed to interpret the evidence. The contract must identify revisions/digests needed to prove that returned text matches the authorized transcript source.
4. The Director may perform zero or one evidence drill-down round per generation. No recursive tool loop, parallel multi-tool fanout or second evidence round is allowed in V1.
5. A tool request outside frozen membership/scope, stale/deleted/retention-ineligible source, malformed request/result, authorization failure or tool execution failure fails closed. The generation outcome is `SYSTEM_ERROR`; it must never be rewritten as `CONTINUE_LISTENING`.
6. A valid no-match result, if the contract permits one for transcript search, must be represented explicitly and deterministically rather than as a transport/tool failure.
7. Diagnostics expose only safe metadata such as stage, error_code, duration and result/reference counts. Do not copy raw evidence/transcript bodies into Decision Trace or logs.
8. Tool contracts remain provider/model/toolkit neutral. Do not select an LLM provider, model, function-calling SDK, tokenizer or production P4 numeric budget.
9. Evidence tools never mutate MemoryClaim/MemoryResolution, transcript, QuestionEvidence, asked/displayed history or P4 membership.
