## Required Behavior

1. Transcript is source truth; memory is derived. Corrections never rewrite original audio or transcript evidence.
2. `Fact` may become accepted/current only when supported by an explicit elder statement in eligible evidence. Do not promote implication, model inference or interviewer suggestion into a Fact.
3. `Episode` may summarize an experienced event/story while preserving evidence membership and uncertainty; it must not silently manufacture explicit Fact fields.
4. `Boundary` represents explicit user/elder intent/control only. Active boundaries are control-only envelopes; source text/evidence body is not copied into Director context.
5. Boundary revocation requires explicit withdrawal/contradiction sufficient under the accepted contract. Absence of repetition is not revocation.
6. Semantic status surface preserves `CURRENT`, `SUPERSEDED`, `UNCERTAIN`, `DISPUTED`; Boundary additionally preserves `ACTIVE`, `REVOKED`, `SUPERSEDED` according to existing accepted semantics. Exact machine mapping must be frozen without inventing incompatible second enums.
7. Correction is non-destructive: create a new revision/resolution or accepted successor state, retain prior revision and evidence, and mark supersession/uncertainty/dispute explicitly.
8. Conflicting eligible evidence must not be silently collapsed. The contract must define deterministic UNCERTAIN/DISPUTED/review-required behavior using existing MemoryResolution authority.
9. Missing evidence, stale/deleted/retention-ineligible evidence, unknown authority, illegal transition, revision mismatch or ambiguous correction fails closed.
10. LLM output is proposal-only. Program validation/persistence owns accepted durable state change.
11. No provider/model/prompt or P6 orchestration decision is made here.
