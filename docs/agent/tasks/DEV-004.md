# DEV-004｜实时 ASR 与说话人映射（父任务）

## 基本信息

- 状态：`IN_PROGRESS`
- 负责人：总控 Agent
- 前置依赖：DEV-003
- 交接对象：DEV-005、DEV-006、项目负责人（GitHub 审查）

## 目标

在不影响原始录音可靠保存的前提下，建立供应商中立、可降级、可追溯的实时转录与会话内说话人映射链路，为访谈工作台和确定态证据消费提供稳定 seam。

## 输入依据

`00` 至 `10`、MVP-V01、ADR-002/006/013/018/019、REV-011/012、HO-016/020/021、CON-014 至 CON-016。

## 子任务顺序

1. DEV-004A：确定态转录证据核心与供应商中立适配器（`DONE`）；
2. DEV-004B1：业务 WebSocket 服务端协议核心、合成 PCM 与短时恢复；
3. DEV-004B2：真实 Chromium 合成 PCM、interim/final 展示、背压与短时重连；
4. DEV-004C：AudioWorklet、说话人校准与人工单段/批量修正；
5. 真实供应商、重连故障区间和离线补转录在供应商/协议明确后另行拆分。

父任务不得因 DEV-004A 或 DEV-004B1 完成而提前 `DONE`。每个后续子任务开工前必须补齐其跨模块契约。

## 全局边界

- 只使用虚构文本、合成音频和隔离数据库；
- ASR 故障不得改变或损害原始录音、audio manifest 和安全结束能力；
- interim 不得进入正式数据库、长期记忆或 AI；
- 原始转录文字与原始说话人角色不可覆盖；
- 不选择真实供应商、不提交密钥、不对公网开放内部夹具；
- 生产 WSS、真实麦克风、长时性能、真实数据合规与 CON-013 仍为真实试点门禁。

## 父任务验收

- 浏览器 PCM 经业务 WebSocket 到供应商中立 adapter，并能实时展示 interim/final；
- final 在 1 秒目标内幂等落库，原文和原角色不可覆盖；
- 会话内说话人校准、未知回退、单段/批量修正与历史保留可验证；
- ASR/WebSocket 故障时录音继续，结束不丢最后 final，缺失区间明确且可补转录；
- 项目负责人按最终 GitHub head 给出 PASS 后才可 `DONE`。
