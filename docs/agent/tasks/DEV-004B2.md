## 浏览器客户端职责

- 使用同源 `ws/wss` URL，获取内存 CSRF 后发送唯一首个 join；
- 生成并复用 `audio_stream_id`，连续生成 100 ms/3200 bytes PCM 的序号、时间和 SHA-256；
- 未 ACK PCM 仅保存在有界内存队列；达到 20 帧或 64000 bytes 时暂停发送，不丢弃、不越过，ACK 后继续；
- 严格按 `event_stream_id/server_sequence` 连续应用事件，成功应用后发送单调 event ACK；
- interim 按 `hypothesis_id + revision` 更新，final 按 `segment_id` 幂等显示；
- 同页面断线时复用 audio/event stream 和最后连续游标，有限退避重连；窗口失效时明确提示 reset，不伪装恢复；
- auth、permission、session、ASR 和 internal failure 分开显示；内部错误文案为“实时转录服务暂时异常，原始录音不受影响”；
- 每 15 秒 heartbeat；卸载时停止 timer、socket 和重连；React StrictMode 下不得形成两个长期 producer；
- 不新增第三方状态管理或 WebSocket 客户端依赖。

- Chromium mock WS：服务端不 ACK 时最多 20 个在途帧，ACK 后恢复。
