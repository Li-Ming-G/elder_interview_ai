## 目标

仅用虚构 PCM 和服务端确定性 streaming fake，建立可鉴权、可背压、可短时恢复且 final 先落库再发布的业务 WebSocket 服务端核心，证明 `WS → fake adapter → DEV-004A ingestion → 有序 interim/final` 最小链路，不提前实现浏览器工作台或真实 ASR。

## 前置依赖与假设

- 使用 Nest 官方 native WebSocket adapter 的静态 path；不使用 Socket.IO，不自建动态 upgrade router；
- 复用现有不透明 session Cookie、`SessionService`、CSRF、assignment 与 DEV-004A ingestion；
- local/test streaming fake 的输出只由服务端帧序决定，客户端不能指定转录文本；
- 只承诺单进程、单 session 单 producer、512 事件或 5 分钟的短时恢复；
- 本任务无 Prisma 变更，无跨进程持久恢复。

## 交付物

- 静态 `/ws/interviews` upgrade 的 Origin/Cookie 失败安全鉴权；
- 5 秒首个 join 的 CSRF、assignment、project/consent/session、单 producer 门禁；
- 正式 contract codec，拒绝未知字段、超限消息和敏感错误回显；
- 16 kHz mono PCM s16le、100 ms/3200 bytes 固定帧校验；
- 连续 sequence、相同帧 ACK 重放、conflict/gap、20 帧/64000 bytes 背压；
- 服务端 `event_stream_id + server_sequence` 严格递增事件、ACK 和 512/5 分钟进程内 replay；
- deterministic local/test streaming fake：可按帧序产生 interim、final 或故障，production 不注册；
- final 经 DEV-004A ingestion 成功后才发布，重复 final 使用稳定 segment ID 且同 runtime stream 不重复发布；
- WebSocket unit/integration/PostgreSQL 证据和安全日志断言。

## 验证方式

- format、lint、typecheck、build、unit；
- 缺失/错误 Origin 与 Cookie 在 upgrade 前 401/403；
- 错 CSRF、无 assignment、restricted/revoked、错误 session 状态无法 join/发帧；
- PCM 格式、长度、checksum、时间、sequence、重放、conflict、gap 与背压测试；
- synthetic PCM 产生 interim 后 final，interim 数据库零行，final 先落库再发事件；
- 重复 final 只保留一行和一个 runtime final 事件；
- server sequence、event ACK、窗口内 replay、过期/重置失败测试；
- fake 故障不改变 session、audio object/chunk/manifest；
- 日志不包含转录正文、PCM/base64、Cookie、CSRF、provider payload 或完整 WS 信封；
- GitHub CI 全门禁通过。

## 验收标准

- 所有 upgrade/join/帧门禁在创建或调用 streaming adapter 前失败关闭；
- 一个 session 同时只有一个 PCM producer，重连只允许符合契约的同流恢复；
- audio sequence 与服务端 event sequence 均单调，重放幂等、冲突稳定；
- 达到背压阈值后不无限缓存，也不改变原始录音链路；
- interim 不落库，final 成功持久化后才发布并携带 DEV-004A 稳定 segment ID；
- 恢复窗口有效时严格 replay，失效时明确 reset，不伪造跨进程恢复；
- production 不可使用 fake，客户端不存在文字/segment/provider payload 注入能力；
- 项目负责人按最终 GitHub head 明确 `PASS` 后才可 `DONE`；父 DEV-004 保持 `IN_PROGRESS`。
