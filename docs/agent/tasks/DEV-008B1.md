## 目标

在 A1/A4 唯一响应式 HomeShell 内实现 project 卡“开始下一次访谈”和 `POST /projects/:id/next-session`，同 project 只创建 sequence+1 session，并在未知响应、刷新、双击和并发下保持稳定幂等。

## 实现范围

- ordinary project mapper 对每行显式投影 `repeat_interview`；restricted/deleted/assignment invalid 与 reader unavailable 失败关闭；
- project action 与 session row/global new-project 动作分离；desktop/mobile/compact 复用同一 HomeShell/routes/tokens；
- request/payload 首次联网前持久化，actor/action/project/payload binding，request→project→session 稳定锁序；
- basis same-project/latest-completed 校验、非终态 session fence、不同 request 并发至多一个 seq+1；
- 新 session 复用既有 device-check/start 端点但建立新 capture/audio/ASR/speaker/calibration/local runtime；
- 普通后续 session 复用仍适用的同 project consent，不新建 consent record/audio/full-consent page；所有正式 start 前显示版本化轻提醒并显式点击“开始访谈”，该点击不是新 consent；
- 接入正式重授权入口与 consent create 的跨 `consent_text_version` 音频拒绝；若实现需要数据库唯一约束或 migration，必须先暂停并另行审查；
- 权限/consent compatibility/reminder version/restricted/deleted/deletion drift 零业务副作用。
