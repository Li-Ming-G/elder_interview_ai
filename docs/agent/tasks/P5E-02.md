## Required Behavior

1. Both tools are pure reads from the perspective of business truth. They do not write transcript, memory, QuestionEvidence, asked/displayed history, P4 context or semantic status.
2. Caller must supply the accepted frozen-generation scope required by P5E-01. The implementation must not infer a wider project/session scope from only an ID or query string.
3. `get_memory_evidence` rejects memory IDs outside the current frozen P4 membership/readability surface and returns only contract-authorized evidence segments plus bounded neighboring context.
4. `search_transcript` searches only the contract-authorized frozen transcript scope and returns deterministic bounded results; it cannot reach untrusted/interim/deleted/retention-ineligible content.
5. Returned transcript text must be checked against the source revision/digest semantics required by the P5E-01 contract. Drift fails closed.
6. Existing authorization, project/session scope, retention, deletion and policy services are reused rather than reimplemented with weaker local checks.
7. All tool failures map to the contract's stable internal error surface so P5E-03 can convert them to `SYSTEM_ERROR`. This task does not itself alter Director outcomes.
8. No provider/model/toolkit/SDK/function-calling/tokenizer/embedding or numeric budget selection.

## Explicit Non-Goals

- No Director invocation or second model call;
- no prompt/schema changes outside the accepted evidence tool contract;
- no Gate/Correction semantic mutation;
- no broad P6 orchestration changes;
- no new agent framework, vector search layer, reranker or arbitrary full-transcript search.

Run targeted tests, relevant memory/transcription/evidence suites, API typecheck, ESLint, Prettier and `git diff --check`.
