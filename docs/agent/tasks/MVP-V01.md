# MVP-V01｜最小纵向核心假设链路

## 目标

用虚构或脱敏数据证明：倾听员能从项目与授权进入一次短访谈，原始资料可靠保留，确定态转录可形成证据关联记忆与候选追问，并能反馈和最小导出。

## 输入依据

`00`、`01`、`03` 至 `10`、ADR-013、任务板及各子任务卡。

## 前置依赖

DEV-001A；DEV-001B 的内部候选 seam `ab9628b`。不要求 DEV-001B 最终 `DONE`。

## 链路与交付物

1. 虚构倾听员登录；
2. 最小长者项目、服务信息、授权状态和访谈会话；
3. 浏览器短时录音，原始分片经本地暂存和服务端幂等保存并生成 manifest；
4. 通过内部测试夹具注入/生成确定态测试转录；
5. 生成至少一条回链转录证据的记忆；
6. 生成一个含原因与证据的候选追问，并记录采用或忽略反馈；
7. 导出该虚构项目的最小原始资料与派生结果清单。

## 允许与禁止范围

- 允许 stub、固定测试音频和内部夹具，但必须明确替换 seam；
- 禁止真实个人信息、真实访谈、真实付费客户、公开访问和默认生产账号；
- 测试转录注入不得成为公开产品 API；
- 禁止为纵向演示覆盖原始录音、原始转录或原始授权；
- 禁止把里程碑通过等同于各子任务 `DONE` 或真实试点通过。

## 验证与验收

- 自动化覆盖各 seam 的输入输出、失败路径和证据关联；
- 一条本地 Chromium 纵向场景可重复运行；
- ASR/AI stub 故障时原始分片仍完整；重复上传不重复保存，manifest 可检测缺失；
- 任务板、追溯矩阵、冲突、决策和交接与实际证据一致。

## 交接对象

总控 Agent；纵向链路集成/产品验证 Agent。真实试点前另行独立验收。
