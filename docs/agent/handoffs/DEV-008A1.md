## 已实现

1. authenticated `/` 成为唯一倾听员 Home/App Shell，复用既有登录、prepare、workbench 路由；共享 `HomeFrame/HomeShell/ListRow/StatusBadge` 与 loading/empty/error/restricted 语义。
2. `GET /projects` 返回 formal `ProjectListResponse`：ordinary 使用正式项目投影；有效 assignment 的 restricted 只返回固定中性最小 DTO；deleted、软删除、assignment 失效无行。
3. `GET /projects/:id/sessions` 使用 `(created_at DESC, id DESC)` keyset、limit+1 和 15 分钟版本化 HMAC cursor；cursor 绑定 project、anchor、方向、limit、filter version，篡改/跨项目/过期/权限漂移失败关闭。
4. session read model 只返回正式最小字段；capture/finalization 只含公开状态，私有 provider failure 归一化，不返回正文、object key、provider payload、created_by/updated_at。`home_state/primary_action/review_access` 完全由服务端矩阵产生，前端不按 completed 猜测。
5. ordinary project/service-term/consent/session/prepare/workbench/review readers 均要求当前有效 assignment + ordinary visibility；restricted/deleted/软删除/assignment 失效失败关闭，session/finalization `created_by` 不再授予普通读取。
6. `GET /sessions/:id/evidence-finalization` 与 recover 降权响应只返回专属 `EvidenceFinalizationResponse`；仅冻结 finalization 的原 actor 可用。既有普通幂等回放在权限丢失后会重新裁剪，不回放项目/会话普通正文；异步 advance 后再次检查权限和 replay binding。
7. Home 按 formal 矩阵导航 prepare/workbench/review/save-facts；review/save-facts 仅在 session list 服务端投影允许时显示共享占位壳，手输 URL 不能绕过。新建访谈只进入“即将可用”壳，不创建 draft、不开始录音。
8. UI 继续使用现有 `styles.css` OKLCH tokens、排版、context-label、button variants、focus-visible、44px 与 reduced motion；无第二套设计系统。
