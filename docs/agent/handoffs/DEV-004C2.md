## 重要决定

- preview TTL 为 15 分钟的服务端实现常量；持久 `expires_at` 是执行权威，不由客户端推导。
- preview membership 保存闭区间全部候选并标记排除；execute 对规范化选择、完整集合、每段 revision、排除结果和 hash 全部复核。
- C2 只生产 revision/operation/affected membership；未触碰 `ai_job`、`memory_item`、`question_suggestion`、`session_note` 或任何 AI 派生状态。
- `$impeccable` 只影响信息层级、行内交互、触控、焦点/live 与小屏遮挡修正，没有改变正式产品语义。
