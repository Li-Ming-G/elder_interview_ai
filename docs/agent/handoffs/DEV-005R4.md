## 实现与最小修复

- 新增服务端内部 `asr-timeline.ts`，在可信边界把恢复代 ASR start/end 映射到 session timeline；gateway 的 interim/final 和 finalization drain 共用同一映射。
- `RealtimeAccessService.assertJoin` 对 produce 返回内部 mode/offset，`SessionRuntime` 持有 immutable offset；wire PCM 仍是 generation-relative。
- 增加恢复代 unit/integration 断言：wire PCM `0..100ms`，服务端 interim/final/drain 从 offset 开始。未修改公共 API、WebSocket schema、Prisma schema、状态枚举或 interruption reason。
- 新增正式路由 R4 Playwright、隔离启动脚本和 Android CDP 只读取证工具；正式产品路由没有 query harness。工具只记录资源 identity、高水位、HTTP path 和媒体对象关联，不读取/保存音频或转录正文。
- 桌面 runner 在系统临时目录运行时生成确定性的纯合成 WAV（2 秒静音基线后进入音调）供 Chromium fake device 使用，并在成功/失败后删除临时目录；仓库不提交音频文件。该修正消除动态噪声基线偶然从恒定音调中采样导致的 E2E 假失败，不改变产品麦克风阈值。
