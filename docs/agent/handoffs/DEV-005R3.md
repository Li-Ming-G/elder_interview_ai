## 实现事实

- `InterviewCaptureController` projection 新增完整 `serverSession`/finalization、最近核验时间/错误与持久 `endHandoff`。工作台先 recover 同一 local job，再持续 GET/focus/online 核验；unknown、未开始、登录/权限/授权或网络异常均失败关闭或保留上次事实，不用 URL、首次 load、计时器或 UI 推断完成。
- 同一工作台 URL 原地呈现 recording/interrupted/stopping/processing/completed/failed/`NO_AUDIO_CAPTURED`。服务端变为 terminal/interrupted 时 controller 采信持久 snapshot，并停止仍在运行的本地 runtime、收最后 archive、释放锁；挂载/刷新/旋转不会自动申请麦克风、resume、创建 session/audio/generation。
- interrupted 保留只读转录，按真实 local job/archive/capture/授权条件提供“继续同一次访谈”“安全结束已有音频”或“结束无音频会话”；resume 只在用户点击后复用同一 session/audio/local job 并请求麦克风。持久结束 handoff 一旦冻结，优先级高于旧 interrupted/recording snapshot，永久禁止继续追加。
- 唯一结束 modal 使用冻结标题/说明/按钮、默认焦点、Escape 和焦点恢复；single-flight 依次完成本地最终写入、stable stop 或 `finalize_interrupted`、delivery flush、audio complete 与服务端复核。stopping 不可收起，processing/completed 可收起，刷新默认展开；没有延时模拟和死的完整回顾入口。
- 顶部只保留长者称呼、时长、安全摘要、结束动作；五类事实进入来源明确的保存明细。转录是唯一主要纵向滚动区，final 不重复标签，interim 仅显示“识别中”；手机始终为 52–64 px 左元数据、右正文。建议区只保留“继续倾听”布局空态。
- 准备页麦克风门禁改为 3.6 秒采样、600 ms 噪声基线、动态阈值与连续帧判定；区分静音/太弱并给出重试说明，但两者均不能通过。非法长者称呼使用“这位长者”，预计时长继续只读正式服务条款，不偷加编辑字段。
