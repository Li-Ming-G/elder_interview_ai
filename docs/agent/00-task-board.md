# 任务看板

## 文件用途

本文件是项目任务状态的唯一动态来源，用于记录任务负责人、依赖、分支、阻塞原因、验收依据和当前状态。根目录 `00-项目说明与执行入口.md` 只提供入口，不重复维护详细状态。

## 状态枚举

`TODO`、`READY`、`IN_PROGRESS`、`BLOCKED`、`REVIEW`、`VERIFY`、`DONE`、`CANCELLED`。
