# Product Flow Closure Matrix

This index records the ordinary listener path covered by PRODUCT-FLOW-CLOSURE-01. Server
responses and the browser capture controller are authoritative for durable state; IndexedDB is
used only for recovery of a browser workflow or audio copy.

| Source route/state | Visible action label | Authoritative prerequisite | Expected destination/result | Failure/recovery behavior | Automated coverage |
| --- | --- | --- | --- | --- | --- |
| `/` Home | `新建访谈` | Existing project/session facts have been checked; no unresolved formal capture blocks creation | `/interviews/new?mode=new`, with an explicit new-intent decision | An unfinished local workflow is shown as `已有一条未完成访谈`; it is not silently resumed | `full-flow.spec.ts` — `new intent exposes an explicit continue choice and preserves workflow identity` |
| `/interviews/new?mode=new` | `继续未完成访谈` | The listener explicitly chooses to retain the active browser workflow | `/interviews/new?mode=resume`, same workflow identity; saved creation-attempt values are restored when present | Existing creation request identity is reused; unsent form input is not durable and no duplicate project is created | `full-flow.spec.ts` — explicit new/continue test |
| `/interviews/new?mode=new` | `放弃未完成访谈并新建` | Server confirms the project has no session, formal audio, or other advanced evidence | Server-backed pre-start discard, then a fresh project form | If server facts cannot authorize discard, the original recovery record remains and the listener is told to return to the workspace | `full-flow.spec.ts` — `server-backed pre-start discard retires the browser recovery pointer` |
| `/interviews/new` · project step | `创建项目并继续` | Required project display name is present | Session step for the newly acknowledged project | The stable request is retained for retry after an unknown response | `full-flow.spec.ts` — primary journey and refresh/reopen test |
| `/interviews/new` · session step | `建立会话并检查麦克风` | Project creation is acknowledged by the server | Consent recording step bound to the created session | The same idempotent session request is recovered; no second session is invented | `full-flow.spec.ts` — primary journey |
| `/interviews/new` · consent recording | `检查当前页麦克风` | A session exists and the current page reports usable microphone input | Device check is persisted for that session; `录制授权` becomes available | Refresh/reopen returns to an unchecked state and requires a new current-page check | `full-flow.spec.ts` — `refresh before formal start requires a fresh microphone check and keeps identity` |
| `/interviews/new` · consent recording | `录制授权` → `停止并保存授权录音` | Current-page microphone check passed; synthetic recording has a durable local chunk | Saved recorded-verbal-consent step | Local audio remains in the same upload job for retry; original evidence is not overwritten | `full-flow.spec.ts` — primary journey |
| `/interviews/new` · saved consent | `确认并登记正式授权` | Consent audio is complete and the fixed text version is acknowledged | Explicit formal-recording reminder step | Consent request identity is retained and replayed safely after an unknown response | `full-flow.spec.ts` — primary journey |
| `/interviews/new` · formal reminder | `开始访谈` | Current server reminder requires an explicit action and valid consent is present | `/projects/:projectId/interview/:sessionId/workbench`, formal capture active | Start failure leaves consent intact and keeps the listener on the preparation step | `full-flow.spec.ts` — primary journey |
| Workbench · calibration gate | `确认说话人` | Formal recording is active and two observed provider labels are available | Ordinary Workbench transcript/suggestion surface; no invented identity | `暂时跳过` or provider-unavailable degrade continues recording without speaker mapping | `full-flow.spec.ts` — primary journey; skip/navigation test |
| Workbench · calibration gate | `暂时跳过` / `跳过说话人确认并继续访谈` | Formal recording is active; skip is explicitly chosen | Workbench remains active with unconfirmed speaker identity | Original recording continues; calibration can be retried where supported | `full-flow.spec.ts` — `calibration skip keeps recording usable, exposes suggestion retry, and guards Back` |
| Workbench · recording | `下一个问题` | Current suggestion projection is available and the session remains recording | Manual-next request is accepted and the suggestion projection is refreshed | Suggestion failure is isolated; recording remains usable and the panel offers `重新加载问题建议` | `full-flow.spec.ts` — primary journey; suggestion-retry assertion |
| Workbench · recording/calibration | Browser Back or route navigation | Formal capture is active or otherwise needs capture attention | Leave dialog; choosing `留在访谈中` keeps the same Workbench active | Navigation is not committed until the listener explicitly chooses safe end-and-leave | `full-flow.spec.ts` — calibration skip/navigation test |
| Workbench · recording/calibration | `结束访谈` → `确认结束` | Formal recording has started; current capture can be safely finalized | Safe stop, upload/finalization, then completion state | The action is available during calibration and preserves already captured evidence | `full-flow.spec.ts` — primary journey; `calibration keeps a safe End Interview action before speaker confirmation` |
| Workbench · completion | `查看回顾` | Server confirms completed session and finalization facts | `/projects/:projectId/interview/:sessionId/review`, read-only review | Incomplete server facts remain in save/processing state rather than being projected as completed | `full-flow.spec.ts` — primary journey |
| Review | `返回工作区` | Review is read-only and session identity is valid | `/` Home; completed session is history with `查看回顾` | Completed session is not offered as resumable `继续准备`; server history remains authoritative | `full-flow.spec.ts` — primary journey |
